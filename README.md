# Untitled Boxing Game
Mini browser boxing game built using vanilla javascript and html5 canvas.

I originally created this project while learning about JavaScript, experimenting with animations, and game logic. 

The project isn't maintained, but it's on my page to show what I've built. I've since moved on from web developing, but it's still nice to see projects I've made before.

### Features
- 2D canvas-based rendering
- Menu and title screen
- Single and two player modes
- Character stats (UI bars)
- Ability to move in real time
- Sprite animation
- Save and load state functionalitGy

### What I've Learned
Honestly this project helped me open my eyes as to what I could make using my knowledge of javascript and what I knew so far. I can't say I was the only one working on it, as I had help from generative ai, at parts where I would get stuck at, frustrated over minor bugs. 

There's a lot to improve with the current code, but the goal at the time was to experiment and see how a simple game could run in the browser.

## How to Play
1. Clone this repository or download the source files as a zip.
2. Open `index.html` in a browser of your choice (chrome recommended)
3. Controls:
   - A/D: Left/Right
   - S: Block
   - Space: Dodge
   - G/H: Jab/Cross
